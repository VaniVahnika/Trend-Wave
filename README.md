# Trend-Wave 🛍️

A modern, responsive e-commerce web application built with React, Vite, Redux Toolkit, Tailwind CSS, and Firebase. Trend-Wave provides a seamless online shopping experience with product browsing, category filtering, cart management, user authentication, and admin product management.

## ✨ Features

- **Product Catalog:** Browse through a variety of trending fashion and lifestyle items.
- **Search & Filters:** Search for products by name and filter by category or price.
- **Shopping Cart:** Add, remove, and update items in real time powered by Redux Toolkit.
- **User Authentication:** Secure user signup, login, and session persistence with Firebase Authentication.
- **Order Management:** View previous orders and purchase details.
- **Admin Dashboard:** Manage products (add, edit, delete) with dedicated protected admin routing.
- **Theme Switcher:** Toggle between light and dark modes.
- **Responsive Design:** Mobile-first layout styled with Tailwind CSS and Headless UI.

## 🚀 Getting Started

### Prerequisites

Ensure you have the following installed:
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/VaniVahnika/Trend-Wave.git
   cd Trend-Wave
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

4. **Build for production:**
   ```bash
   npm run build
   ```

5. **Preview production build:**
   ```bash
   npm run preview
   ```
